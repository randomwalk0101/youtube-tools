# Windows Scripts

PowerShell scripts for YouTube Tools.

## Requirements

- Windows 10 or Windows 11
- PowerShell
- yt-dlp.exe
- ffmpeg.exe

Make sure `yt-dlp.exe` and `ffmpeg.exe` are available in PATH.

## Usage

Run PowerShell in the project folder:

```powershell
.\windows\ytcut.ps1
.\windows\ytaudio.ps1
.\windows\ytsub.ps1
.\windows\ytdl.ps1
